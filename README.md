# 🌦️ Weather App

A simple Android weather application built with **Kotlin** and the **OpenWeatherMap API**.

## Features

* Search weather by city
* View temperature, weather condition, humidity, and wind speed
* Handles invalid cities and network errors

## Tech Stack

* Kotlin
* Android
* XML
* Retrofit
* Gson
* OpenWeatherMap API

## Setup

1. Clone the repository.
2. Add your OpenWeatherMap API key to `local.properties`:

```properties
WEATHER_API_KEY = 6f801927cfe8b6af82bb62e17b50b87c
```

3. Open the project in Android Studio.
4. Build and run the app.

> The API key is loaded through `BuildConfig` and is not stored directly in the source code.
